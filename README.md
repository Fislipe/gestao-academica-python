# Sistema de Gestão Acadêmica - CRUD Python

Este projeto consiste em um software de gerenciamento de dados escolares desenvolvido como parte das atividades acadêmicas no IFC (Instituto Federal Catarinense). A aplicação foca na manipulação estruturada de registros de alunos e professores através de uma interface de terminal.

## Funcionalidades
- Cadastro de novos registros no sistema.
- Consulta e listagem de dados armazenados.
- Alteração e exclusão de informações existentes (Operações CRUD).
- Persistência de dados em arquivos locais para preservação da informação.

## Estrutura Técnica
O sistema utiliza conceitos de manipulação de matrizes para a organização dos dados em memória e operações de I/O (entrada/saída) de arquivos para garantir a integridade dos dados após o encerramento da aplicação.

## Como utilizar
1. Extraia os arquivos do repositório.
2. Execute o script principal em ambiente Python 3.x.
3. Utilize o menu numérico para navegar entre as funções de gerenciamento.
