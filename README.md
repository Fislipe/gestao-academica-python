# Sistema de Gestão Acadêmica - CRUD Python

Este projeto consiste em um software de gerenciamento de dados escolares desenvolvido em Python. A aplicação permite a manipulação completa de registros de alunos e professores através de uma interface de terminal estruturada.

## Funcionalidades
- Cadastro de novos registros no sistema.
- Consulta e listagem de dados armazenados.
- Alteração e exclusão de informações existentes.
- Persistência de dados em arquivos locais.

## Estrutura Técnica
O desenvolvimento utilizou conceitos de manipulação de matrizes para organização dos dados em memória e operações de I/O (entrada/saída) de arquivos para garantir que as informações sejam preservadas após o fechamento da aplicação.

## Como utilizar
1. Clone o repositório.
2. Execute o arquivo principal: python main.py
3. Utilize o menu numérico para navegar entre as funções do sistema.
