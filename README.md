#  Mazza's Pizza - Projeto IFC

Projeto desenvolvido como atividade prática para a disciplina de informática no **IFC Campus Concórdia**. O site é uma plataforma institucional e de pedidos para a pizzaria do Chef Mazzutti.

## 🚀 Tecnologias Utilizadas

* **HTML5**: Estrutura semântica e organizada.
* **CSS3**: Design personalizado com foco em legibilidade e alto contraste.
* **JavaScript**: Lógica dinâmica para adição de itens e cálculo automático do valor total do pedido.

##  Estrutura do Projeto

O repositório está organizado da seguinte forma para garantir o funcionamento dos links:

* `/css`: Contém todos os arquivos de estilização (`css.css`, `cardapio.css`, `sobre.css`, `pedido.css`).
* `/imgs`: Armazena todas as imagens e ícones do projeto em formato `.png`.
* `index.html`: Página principal (Home).
* `cardapio.html`: Cardápio detalhado com pizzas, bebidas e doces.
* `sobre.html`: História da pizzaria e contatos.
* `pedido.html`: Formulário de pedidos.
* `pedido.js`: Lógica de programação do carrinho de compras.
